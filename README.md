# visp-hyper-agent

Local-first companion workflow controller for Codex, Claude Code, GitHub Copilot, OpenCode, and similar AI coding tools.

Visp Hyper Agent does not replace coding agents. It prepares compact context, reads Visp-Kit and Visp-Memory artifacts, prints an LLM-readable handoff protocol, and gives the active coding tool a disciplined session workflow.

## Status

This repository is in skeletal MVP setup.

Implemented command surface:

- `visp-hyper init`
- `visp-hyper start "<goal>"`
- `visp-hyper next`
- `visp-hyper status`
- `visp-hyper checkpoint`
- `visp-hyper review`
- `visp-hyper remember`

## Development

Prerequisites:

- Node.js 24+
- pnpm 11+

Install and verify:

```bash
pnpm install
pnpm check
```

Run locally:

```bash
pnpm build
node dist/index.js init
node dist/index.js start "implement offline note sync" --tool codex
```

## Architecture

The MVP keeps the orchestration layer in TypeScript and uses local files for memory:

- `.visp/hyper/` stores Visp Hyper session state and current handoff files.
- `.visp/memory/` stores local-first project memory and session history.
- `.visp/` artifacts generated by Visp-Kit are consumed, not duplicated.

Future memory integration should add a `LlmMemoryProvider` adapter to the Python `llm-memory` / `visp-memory` project.
